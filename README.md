# Word Counter Tool

A free online word counter and text analysis tool built with Next.js 14, TypeScript, and Tailwind CSS.

## Features

- **Real-time Analysis**
  - Word count (with and without spaces)
  - Character count (with and without spaces)
  - Sentence and paragraph count
  - Line count

- **Advanced Metrics**
  - Reading time estimation (200 words/min)
  - Speaking time calculation (150 words/min)
  - Flesch-Kincaid readability score
  - Average word and sentence length

- **Keyword Analysis**
  - Top 10 keywords with frequency
  - Keyword density percentage
  - Automatic stop word filtering

- **User Features**
  - Copy text to clipboard
  - Clear text with one click
  - Export analysis as text file
  - Mobile-responsive design

## Tech Stack

- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS
- Lucide React icons

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the app.

## Deployment

This app is configured for deployment on Vercel:

```bash
vercel --prod
```
